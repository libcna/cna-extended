RENDER READBACK

Resolve the render target before reading it.

CNA’s GraphicsDevice::GetBackBufferData reads the presentation backbuffer. Use the render target’s own GetData for offscreen pixels.

offscreen pixel test
graphicsDevice.SetGraphicsProfileEXT(GraphicsProfile::HiDef);
RenderTarget2D renderTarget(graphicsDevice, width, height);
graphicsDevice.SetRenderTarget(&renderTarget);
graphicsDevice.Clear(Color::Black);
// draw
graphicsDevice.SetRenderTarget(nullptr); // resolve
renderTarget.GetData(pixels.data(), static_cast<int>(pixels.size()));
!

For overlapping 3D objects, create the target with a depth format and clear depth as well as color. The three-argument target constructor has no depth buffer.
