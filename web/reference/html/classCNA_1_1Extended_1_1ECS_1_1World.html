Detailed Description

The central ECS container: owns EntityManager/ComponentManager, registers and runs Systems each Update/Draw.

See also
WorldBuilder, the normal way to construct a World with its systems already registered (prefer it over this class's own constructor – see WorldBuilder's own doc comment).
Entity, created via CreateEntity() and used to attach/query components.
