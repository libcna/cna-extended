7// 3D counterpart of CNA::Extended::Graphics::AnimatedSprite. Builds on this project's
8// already-ported Graphics::SpriteSheet/Texture2DAtlas (named animation frames as atlas
9// regions) and Animations::AnimationController (frame-timing/looping) exactly as
10// AnimatedSprite itself does (see AnimatedSprite.cpp) -- reused, not reinvented: this
11// component only pairs an AnimationController with the sibling BillboardComponentEXT
12// AnimatedBillboardSystemEXT keeps in sync (see that system's header comment).
13//
14// Must be attached alongside a BillboardComponentEXT on the same entity:
15// AnimatedBillboardSystemEXT reads/writes that sibling component's TextureEXT/
16// VertexBufferEXT each time the current frame changes; BillboardRenderSystemEXT does the
17// actual drawing, unaware this component even exists.
