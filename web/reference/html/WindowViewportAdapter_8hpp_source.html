5// Ported from MonoGame.Extended's ViewportAdapters/WindowViewportAdapter.cs: an adapter whose
6// virtual resolution always tracks the window's client area exactly (no scaling), updated live via
7// GameWindow::ClientSizeChanged. GameWindow is taken by reference, matching ViewportAdapter's own
8// GraphicsDevice& convention -- the adapter never owns the window. Upstream never unsubscribes
9// from ClientSizeChanged (only BoxingViewportAdapter's Dispose() does, for its own subscription) --
10// preserved exactly, not "fixed": if a WindowViewportAdapter outlives its subscription's usefulness
11// but the window itself outlives the adapter, the dangling subscription is upstream's own
12// behavior, not introduced by this port.
