5// Ported from MonoGame.Extended's Tilemaps/TilemapWorld.cs. Constructed from a list of
6// already-built `Tilemap` levels handed over by a parser -- following the same
7// canonical-single-owner reasoning already established for `TilemapTilesetCollection`
8// (nothing else keeps a reference to a level once it's handed to a world), `Levels` is an
9// owning `std::vector<std::unique_ptr<Tilemap>>`. Upstream's `ArgumentNullException.
10// ThrowIfNull(levels)` checks that the *list reference itself* isn't null -- a concept with
11// no C++ equivalent here, since a `std::vector` parameter can never be null (only empty), so
12// it is not translated (matching this project's established convention for reference-type
13// null checks that become unrepresentable once the parameter type can't be null).
