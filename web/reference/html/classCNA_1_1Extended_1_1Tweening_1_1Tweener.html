Detailed Description

Manages a collection of active tween animations and drives their updates each frame. Create animations with TweenTo() (pointer-to-member syntax, not a lambda selector – see this header's own top comment for why), then call Update() once per frame from your game's own Update() loop.

See also
EasingFunctions for the built-in easing curves passed to TypedTween::Easing().
#include <CNA/Extended/Tweening/EasingFunctions.hpp>
#include <CNA/Extended/Tweening/Tweener.hpp>
#include <Microsoft/Xna/Framework/Vector2.hpp>
using CNA::Extended::Tweening::EasingFunctions;
using CNA::Extended::Tweening::Tweener;
using Microsoft::Xna::Framework::Vector2;
struct Player { Vector2 Position{0.0f, 0.0f}; };
void StartMoveAnimation(Tweener& tweener, Player& player)
{
tweener.TweenTo(&player, &Player::Position, Vector2(100.0f, 0.0f), 0.5f)
->Easing(EasingFunctions::QuadraticOut);
}

◆ getActiveTweensProperty()

std::vector< Tween * > CNA::Extended::Tweening::Tweener::getActiveTweensProperty ( ) const
inline

Returns a read-only, non-owning view of the currently active tweens.

C++ counterpart of upstream's ReadOnlySpan<Tween> ActiveTweens (a zero-copy span over the backing List<Tween>, via CollectionsMarshal.AsSpan). This port stores tweens as std::vector<std::unique_ptr<Tween>> (Tweener owns tween lifetime here, unlike upstream's GC-tracked list), so a true zero-copy Tween* view isn't directly achievable without exposing the internal unique_ptr storage – this materializes a fresh std::vector<Tween*> of non-owning pointers on each call instead: not zero-allocation like upstream, but the same practical capability (inspect .size(), iterate elements), which is what every real upstream call site actually uses this for.

Returns
Non-owning pointers to each active tween, valid until the next call that adds or removes a tween (TweenTo/Update/CancelAll/CancelAndCompleteAll).

Creates and starts an animation that interpolates the specified member of target from its current value to toValue over duration seconds. If an animation is already running on the same (target, member) it is cancelled first.

Template Parameters
TTargetThe type of the target object.
TMemberThe value type of the member being animated.
Parameters
targetThe object whose member will be animated. Must outlive the returned tween.
memberPointer to the public data member to animate.
toValueThe target value to animate towards.
durationThe duration of the animation in seconds.
delayAn optional delay before the animation begins, in seconds.
Returns
The created tween, for fluent configuration. Owned by this Tweener; do not delete.
