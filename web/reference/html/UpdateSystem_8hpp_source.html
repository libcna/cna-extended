7// `ISystem` is inherited *virtually* here (and by `IDrawSystem`, and by `EntitySystem`):
8// `EntityUpdateSystem : EntitySystem, IUpdateSystem` (see EntityUpdateSystem.hpp) reaches
9// `ISystem` via two separate paths -- through `EntitySystem` and through `IUpdateSystem` -- the
10// same way C#'s interface model always resolves a diamond-shaped interface hierarchy to one
11// shared set of members regardless of how many paths reach it. C++ needs `virtual` inheritance
12// spelled out explicitly to get that same single-shared-base behavior; without it,
13// `EntityUpdateSystem` would have two distinct, ambiguous `ISystem` subobjects and
14// `dynamic_cast<IUpdateSystem*>`/`dynamic_cast<IDrawSystem*>` (used by `World::RegisterSystem` to
15// sort systems into the update/draw bags) would not behave correctly.
