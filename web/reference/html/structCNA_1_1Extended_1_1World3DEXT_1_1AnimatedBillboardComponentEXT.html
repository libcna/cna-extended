Detailed Description

ECS component pairing a SpriteSheet (named animations as texture atlas regions) with a per-entity AnimationController, advanced by AnimatedBillboardSystemEXT.

See also
AnimatedBillboardSystemEXT, which advances ControllerEXT and updates the sibling BillboardComponentEXT's texture/UV on each frame change.
