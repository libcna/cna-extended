Detailed Description

template<typename TTarget, typename TMember>
class CNA::Extended::Tweening::LinearTween< TTarget, TMember >

A tween that animates a value of type TMember using linear interpolation via TMember's own operator+/operator-/operator* overloads.

Template Parameters
TTargetThe type of the target object.
TMemberThe value type to animate. Must support operator+(TMember,TMember), operator-(TMember,TMember), and operator*(TMember,float).
