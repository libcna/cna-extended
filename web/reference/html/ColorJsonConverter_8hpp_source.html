5// Ported from MonoGame.Extended's Serialization/Json/ColorJsonConverter.cs. Upstream is a C#
6// `JsonConverter<T>` class, opted into per-call via `JsonSerializerOptions.Converters.Add(...)`.
7// `sharp-runtime`'s `JsonSerializer` has no per-call converter registration -- it dispatches
8// exclusively through nlohmann's global ADL customization points (see JsonSerializer.hpp's own
9// header comment: this is a deliberate, documented reflection replacement, not an omission). Since
10// `Color` is a foreign type this project doesn't own the definition of (it lives in `cna`'s
11// `Microsoft::Xna::Framework`), free `to_json`/`from_json` functions in that type's own namespace
12// aren't an option here (unlike the TexturePacker DTOs, which this project *does* own). nlohmann's
13// own documented mechanism for exactly this situation is a `nlohmann::adl_serializer<T>` full
14// specialization -- used here and by every other value-type converter in this module
15// (HslColor/Vector2/RectangleF/Thickness/SizeF/Interval<T>). The practical effect matches
16// registering the converter once and using it everywhere, which is how every real caller in this
17// codebase actually uses these types today; there is no plain (non-hex-string) JSON representation
18// of `Color` anywhere else in this project to conflict with.
19//
20// `from_json` is the return-by-value form (`static T from_json(const json&)`), not the out-param
21// form (`static void from_json(const json&, T&)`) nlohmann's own examples usually show: `Color`
22// has no default constructor (confirmed by reading Color.hpp -- every constructor is parameterized
23// or `explicit`), and the out-param form requires nlohmann to default-construct a `T` first, which
24// fails silently at the SFINAE level (not a helpful error at the actual call site) for
25// non-default-constructible types. Verified empirically with a minimal repro. The return-by-value
26// form works for both default- and non-default-constructible types alike, so it's used
27// consistently across every converter in this module, not just for `Color`.
