Detailed Description

Polls mouse state each Update() and raises click/double-click/drag/move/wheel events.

Remarks
Due to the nature of the listener, it continues to be updated even when the game is not in focus. Register with InputListenerComponent to avoid this, or pause Update() manually when the game loses focus.
