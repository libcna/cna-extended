5// Ported from MonoGame.Extended's Content/TexturePacker/TexturePackerFileContent.cs. Upstream's
6// `record`s with `[property: JsonPropertyName(...)]` positional properties -> get-only
7// getXProperty() classes here (matching this project's C# read-only-property convention), each
8// with a `from_json` free function providing the custom JSON-key-name mapping that
9// `JsonPropertyName` supplies in C# (sharp-runtime's `JsonSerializer::Deserialize<T>` uses
10// nlohmann's ADL `from_json` customization point in place of reflection -- see
11// `System/Text/Json/JsonSerializer.hpp`'s own header comment). Only `from_json` is provided, not
12// `to_json`: this format is never written by this project (upstream's writer,
13// `TexturePackerWriter.cs`, lives in the excluded `MonoGame.Extended.Content.Pipeline` assembly).
