4// CNA::Extended::World3DEXT::Octree3DEXT -- new, non-upstream addition. See 3d.md/plan3d.md
5// at the repository root for the design.
6//
7// 3D counterpart of CNA::Extended::Collisions::QuadTreeSpace: a thin ICollisionBroadphase3DEXT
8// adapter wrapping an OctreeNode3DEXT root node. Owns every OctreeNodeData3DEXT it creates
9// in Insert (see OctreeNodeData3DEXT.hpp's header comment for the full ownership rationale)
10// via std::unordered_map<ICollisionActor3DEXT*, std::unique_ptr<OctreeNodeData3DEXT>> -- the
11// octree/its nodes only ever hold non-owning OctreeNodeData3DEXT* references into instances
12// owned here, mirroring QuadTreeSpace.hpp's own rationale.
13//
14// This is a real recursive-subdivision octree, brought to parity with
15// CNA::Extended::Collisions::QuadTree (2026-07-14, user-requested), unlike SpatialHash3DEXT
16// (a uniform fixed-cell grid hash). It is NOT CollisionWorld3DEXT's default broadphase --
17// SpatialHash3DEXT still is -- usable via the existing
18// CollisionWorld3DEXT(std::unique_ptr<ICollisionBroadphase3DEXT>) constructor, exactly as
19// SpatialHash3DEXT.hpp's own header comment already promised ("nothing... precludes swapping
20// it in").
