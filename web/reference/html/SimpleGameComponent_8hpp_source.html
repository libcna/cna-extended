5// Ported from MonoGame.Extended's SimpleGameComponent.cs: a lighter-weight abstract base for
6// update-only components that don't need a Game reference (unlike CNA's own GameComponent, which
7// stores one). Implements CNA's IGameComponent/IUpdateable/System::IDisposable/
8// System::IComparable<GameComponent>/System::IComparable<SimpleGameComponent>, following the same
9// event-handling pattern established by GameComponent.hpp/.cpp and FramesPerSecondCounter.hpp/
10// .cpp (System::Object base, public EventHandler<EventArgs> members, Raise(this,
11// EventArgs::Empty)).
12//
13// C#'s explicit interface implementation (`bool IUpdateable.Enabled => _isEnabled;`, distinct
14// from the public `IsEnabled` property of the same underlying field) has no direct C++
15// equivalent, but is approximated here: getEnabledProperty() overrides IUpdateable's pure
16// virtual as a *private* member (callable through an IUpdateable& reference via virtual dispatch,
17// exactly like upstream's interface-only access, but not part of SimpleGameComponent's own public
18// API surface), while getIsEnabledProperty()/setIsEnabledProperty() are the real public API,
19// matching upstream's own choice of a different public name (IsEnabled, not Enabled). Both
20// getters return the same underlying value -- this is purely a visibility/naming distinction in
21// upstream too, not a behavioral one.
