Detailed Description

Draws a Tilemap3DEXT as a small number of batched, per-chunk/per-texture draw calls (only visible tile faces included), instead of TilemapRenderer3DEXT's one draw call per tile.

See also
TilemapRenderer3DEXT, the simpler per-tile alternative this doesn't replace.
