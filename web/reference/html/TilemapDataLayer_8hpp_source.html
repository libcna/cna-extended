5// Ported from MonoGame.Extended's Tilemaps/TilemapLayers/TilemapDataLayer.cs. A layer that
6// carries data but has no visual tiles; the renderer skips data layers entirely. Data layers
7// carry format-specific information that does not correspond to renderable content (e.g.
8// collision-type grids or region-tag grids). The data is stored in TilemapLayer's Properties;
9// its meaning is defined by the source format and the game -- this project does not interpret
10// the property values.
