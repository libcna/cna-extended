7// Bridges this project's existing CNA::Extended::Transform3 (already ported from
8// MonoGame.Extended's Transform.cs -- a dirty-flag-optimized parent/child transform
9// hierarchy, see Transform.hpp) into the ECS: Transform3 itself only knows about a parent
10// *pointer* (another Transform3*), not a parent *entity*, so it has no way on its own to
11// express "my parent is entity 7" the way an ECS scene graph needs. This component adds
12// exactly that -- a ParentEntityIdEXT the TransformHierarchySystemEXT (see that file)
13// resolves into a real Transform3::setParentProperty() call each frame. Transform3's own
14// dirty-flag/world-matrix-recompute machinery is reused entirely unchanged; this component
15// adds no new hierarchy logic of its own.
