Detailed Description

Represents a color in the HSL (Hue, Saturation, Lightness) color space.

Hue (H) represents the color, ranging from 0 to 360 degrees on the color wheel. Saturation (S) represents the intensity of the color, ranging from 0.0 (gray) to 1.0 (full color). Lightness (L) represents the brightness, ranging from 0.0 (black) to 1.0 (white).
