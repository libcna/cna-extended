5// Ported from MonoGame.Extended's Animations/IAnimationController.cs. Notable translation
6// decisions:
7// - `event Action<IAnimationController, AnimationEventTrigger> OnAnimationEvent;` is a genuine
8// 2-parameter multicast Action, not the (sender, args) EventHandler<TEventArgs> shape used
9// elsewhere in this port -- translated as System::MulticastAction<IAnimationController*,
10// AnimationEventTrigger>, exposed via a getOnAnimationEventEvent() accessor returning a
11// reference, matching the getEnabledChangedEvent()/getUpdateOrderChangedEvent() accessor
12// pattern IUpdateable already uses for interface-level events in this ecosystem (see
13// Microsoft::Xna::Framework::IUpdateable).
14// - `bool Play()` / `bool Play(int startingFrame)`, `bool Pause()` / `bool Pause(bool
15// resetFrameDuration)`, and `bool Unpause()` / `bool Unpause(bool advanceToNextFrame)` are each
16// a parameterless overload that forwards to the parameterized one with a fixed default
17// (upstream: `Play() => Play(0)`, etc.) -- collapsed into a single virtual with a default
18// argument per pair, which is behaviorally identical and more idiomatic C++ than mirroring two
19// separate pure virtuals per pair.
20// - `void Update(GameTime gameTime)` takes gameTime by value in C# but only reads
21// gameTime.ElapsedGameTime; translated as `const GameTime&` (this interface does not implement
22// IUpdateable, so it is not bound to that interface's `GameTime&` convention).
23// - `ArgumentOutOfRangeException` thrown by SetFrame/Play(int) is a concrete-implementation
24// detail (AnimationController.cpp), not representable on the interface itself.
