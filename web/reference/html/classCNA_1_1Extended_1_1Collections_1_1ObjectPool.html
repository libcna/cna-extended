Detailed Description

template<typename T>
class CNA::Extended::Collections::ObjectPool< T >

A pool of IPoolable-implementing instances, tracking free items in O(1) and in-use items in an iterable intrusive linked list.

Template Parameters
TThe pooled type; must derive from IPoolable.
