class  CNA::Extended::Graphics::AnimatedSprite
 A Sprite that plays a named SpriteSheet animation, advancing its TextureRegion frame-by-frame over time. This is the usual way to animate a character/effect: define the animation once on a shared SpriteSheet (SpriteSheet::DefineAnimation), then create one AnimatedSprite per on-screen instance and call Update() each frame.
