6// `Texture2DRegionExtensions`, matching the static class name rather than the file name, per this
7// project's convention of naming extension-method headers after the class they extend). Extension
8// methods -> free functions in this namespace. `textureRegion` is nullable in C# (extension
9// methods may be invoked on a null receiver, and the null is checked inside the method body), so
10// it is taken here as `const std::shared_ptr<Texture2DRegion>&`, matching Texture2DRegion.hpp's
11// shared-ownership convention, with an explicit std::invalid_argument check reproducing
12// ArgumentNullException.ThrowIfNull. `GetSubregion` returns a null shared_ptr when the requested
13// subregion does not intersect the trimmed bounds (upstream returns C# null).
