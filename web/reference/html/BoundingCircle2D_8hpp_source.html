5// Ported from MonoGame.Extended's BoundingCircle2D.cs. Now that Collision2D has landed (Phase 2),
6// all upstream Contains(...)/Intersects(...)/TryGetCollision(...) overloads are ported below as
7// thin wrappers delegating to the matching Collision2D::ContainsCircleXxx/IntersectsCircleXxx/
8// TryGetCollisionCircleXxx static method, using this circle's Center/Radius plus the other
9// shape's own public fields -- except TryGetCollision(BoundingPolygon2D), which upstream itself
10// never defines (there is no Collision2D.TryGetCollisionCircleConvexPolygon in the C# source
11// either): Contains/Intersects both have full Circle/Aabb/Circle/Obb/Capsule/ConvexPolygon
12// coverage (6 and 5 overloads respectively), but TryGetCollision only covers Circle/Aabb/Obb/
13// Capsule (4 overloads) -- a genuine upstream asymmetry, preserved faithfully rather than
14// "completed" with an invented overload.
