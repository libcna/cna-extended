7// Not a literal 1:1 port of CNA::Extended::Particles::Modifiers::VortexModifier: 2D's vortex
8// rotates a 2D gravitational force around a single point (the whole 2D plane has one implicit
9// rotation axis, perpendicular to the screen). Per the approved plan, the 3D generalization
10// rotates around an explicit AxisEXT line (through TriggeredPositionEXT + PositionEXT), not a
11// single point -- particles are pulled toward/around that line, not a sphere center. The
12// radial distance used for InnerRadiusEXT/OuterRadiusEXT and the 1/distance force falloff is
13// measured perpendicular to AxisEXT (the displacement vector's component orthogonal to the
14// axis), and "rotating the gravity vector by RotationAngleEXT" becomes a proper rotation
15// around AxisEXT via Rodrigues' rotation formula restricted to a vector already perpendicular
16// to the axis (v*cos(theta) + (axis x v)*sin(theta)), which is exactly the identity a 2D
17// rotation matrix computes when AxisEXT is the implicit 2D screen-normal -- so this is a true
18// generalization, not an unrelated new algorithm.
