5// Ported from MonoGame.Extended's BoundingCapsule2D.cs. Upstream's Contains(...)/Intersects(...)/
6// TryGetCollision(...) overloads all delegate to static query functions on MonoGame.Extended's
7// Collision2D type, and CreateFromSegment/CreateMerged delegate to LineSegment2D's
8// DistanceToPoint/DistanceSquaredToPoint -- now that Collision2D and LineSegment2D are both fully
9// ported (Phase 2), all of them are landed below: 6 Contains (point, aabb, circle, obb, self,
10// polygon), 5 Intersects (self, circle, aabb, obb, polygon), and CreateFromSegment/CreateMerged.
11//
12// Asymmetric coverage (matching Collision2D exactly, not an omission): Collision2D provides only
13// one TryGetCollision* function involving a capsule -- TryGetCollisionCircleCapsule -- so
14// TryGetCollision(BoundingCircle2D, CollisionResult2D&) is the only TryGetCollision overload landed
15// here. Upstream has no TryGetCollision(BoundingBox2D)/TryGetCollision(OrientedBoundingBox2D)/
16// TryGetCollision(BoundingCapsule2D)/TryGetCollision(BoundingPolygon2D) either, and Collision2D
17// itself has no matching TryGetCollisionAabbCapsule/TryGetCollisionObbCapsule/
18// TryGetCollisionCapsuleCapsule/TryGetCollisionCapsuleConvexPolygon functions to wrap -- confirmed
19// by reading Collision2D.hpp -- so there is genuinely nothing more to wrap.
20//
21// TryGetCollision(BoundingCircle2D) calls Collision2D::TryGetCollisionCircleCapsule (Collision2D
22// has no TryGetCollisionCapsuleCircle) and then calls .Invert() on the result, since
23// TryGetCollisionCircleCapsule's MTV convention moves the circle out of the capsule, but this
24// method's contract moves the capsule out of the circle -- matching upstream exactly.
