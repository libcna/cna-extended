Detailed Description

Convenience Screen base class owning an ECS::World + Camera3DEXT, tying together every World3DEXT system from Phases 1-8.

See also
Screens::Screen, whose Load/Update/Draw lifecycle this class reuses unchanged.
ConfigureWorldEXT, the hook derived classes override to add their own systems.
