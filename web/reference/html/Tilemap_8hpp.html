class  CNA::Extended::Tilemaps::Tilemap
 The runtime tile/layer/tileset data model for a loaded map, independent of which source format it came from (Tiled TMX/JSON, LDtk JSON, or Ogmo JSON). Every format-specific parser converges on this same representation, so rendering, coordinate conversion, and gameplay code written against Tilemap never needs to know or care which format a given map was authored in.
