4// CNA::Extended::World3DEXT::ParticleEmitter3DEXT -- new, non-upstream addition. See
5// 3d.md/plan3d.md at the repository root for the design.
6//
7// 3D counterpart of CNA::Extended::Particles::ParticleEmitter. Originally deliberately
8// scoped down (one built-in cone emission shape, three behaviors baked directly into
9// UpdateEXT); brought to parity with 2D's full Profiles/Modifiers/Interpolators plugin
10// architecture (2026-07-14, user-requested) via Profile3DEXT/Modifier3DEXT/
11// Interpolator3DEXT (see those files' own header comments for the full design, including
12// Modifier3DEXT's documented deviation in how Frequency-throttling interacts with elapsed
13// time).
14//
15// Design note on which fields moved and which didn't (deliberately minimal blast radius on
16// this class's own public surface, not a blanket "everything moves to a plugin object"
17// rule): ConeDirectionEXT/ConeHalfAngleEXT moved to ConeProfile3DEXT (getProfileEXTProperty())
18// -- a user-confirmed decision specifically about these two fields, since 2D's own analogous
19// per-shape configuration (e.g. SprayProfile::Direction/Spread) genuinely lives on the
20// Profile object, not the emitter. StartColorEXT/EndColorEXT/StartOpacityEXT/EndOpacityEXT/
21// GravityEXT stay exactly where they were (unscoped, zero pre-existing test changes needed)
22// -- UpdateEXT syncs them into the default AgeModifier3DEXT's owned ColorInterpolator3DEXT/
23// OpacityInterpolator3DEXT and the default LinearGravityModifier3DEXT each call, so the
24// public configuration surface for these is unchanged while the new architecture still
25// genuinely drives the default per-frame pipeline end-to-end (not bypassed).
26//
27// AgeEXT/PositionEXT integration stays baked directly in UpdateEXT's own loop, matching 2D's
28// own ParticleEmitter::Update, which likewise bakes basic age/position integration in
29// directly rather than driving it through a Modifier -- see AgeModifier3DEXT.hpp.
