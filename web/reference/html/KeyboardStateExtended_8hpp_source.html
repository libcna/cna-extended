5// Ported from MonoGame.Extended's Input/KeyboardStateExtended.cs. Upstream has an `#if FNA`
6// branch for CapsLock/NumLock (using IsKeyDown(Keys.CapsLock/NumLock) since FNA's KeyboardState
7// has no native CapsLock/NumLock properties) and a non-FNA branch (using
8// KeyboardState.CapsLock/NumLock directly). CNA mirrors FNA (an established precedent throughout
9// this project, e.g. RectangleExtensions), so the FNA branch applies unconditionally here.
10//
11// `GetPressedKeyCount` (upstream: `_currentKeyboardState.GetPressedKeyCount()`, an FNA extension
12// method backed by a `GetPressedKeys().Length` computation -- see KeyboardState.Extensions.cs) ->
13// `getPressedKeys().size()`. CNA's own KeyboardState::GetPressedKeys() already returns a
14// self-sizing std::vector<Keys>, so there is no separate count-then-fill-array API to port --
15// upstream's `GetPressedKeys(Keys[] keys)` fill-into-existing-array overload has no C++
16// equivalent need and is intentionally not ported (CNA's GetPressedKeys() already returns a
17// complete, appropriately-sized vector in one call).
