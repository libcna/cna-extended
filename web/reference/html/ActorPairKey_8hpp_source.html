5// Ported from MonoGame.Extended's Collisions/ActorPairKey.cs: an order-independent key
6// identifying an unordered actor pair (used to de-duplicate collision-pair query results).
7// Upstream's `internal` visibility has no C++ equivalent; kept public, matching the precedent set
8// by CollisionResult2D::Invert()/CollisionShapeKind2D elsewhere in this port. The constructor
9// takes ICollisionActor by const reference rather than by pointer -- C++ references cannot be
10// null, so upstream's `ArgumentNullException.ThrowIfNull(first)`/`ThrowIfNull(second)` checks have
11// no C++ equivalent to preserve and are naturally dropped, matching how this project translates
12// non-nullable C# reference-type parameters elsewhere.
