class  CNA::Extended::Particles::ParticleEmitter
 Creates, updates, and manages the particles emitted by one emission source within a particle effect. An emitter's Profile controls where new particles start (point, line, circle, box, ...), Parameters controls their initial values (velocity, color, scale, lifetime, ...), and Modifiers apply per-frame forces/interpolation (gravity, drag, color- over-time, ...) to particles already in flight.
