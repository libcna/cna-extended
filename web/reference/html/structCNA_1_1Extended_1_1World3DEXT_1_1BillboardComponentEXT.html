Detailed Description

ECS component for a camera-facing textured quad ("billboard"), drawn by BillboardRenderSystemEXT using Matrix::CreateBillboard each frame.

See also
BillboardRenderSystemEXT, which draws this component.
BuildBillboardQuadVertexBufferEXT, the helper that builds VertexBufferEXT.
