5// Ported from MonoGame.Extended's BoundingBox2D.cs. Upstream's Contains(...)/Intersects(...)/
6// TryGetCollision(...) overloads all delegate to static query functions on MonoGame.Extended's
7// Collision2D type -- now that Collision2D is fully ported (Phase 2), all of them are landed
8// below: 6 Contains (point, self, circle, obb, capsule, polygon), 5 Intersects (self, circle,
9// capsule, obb, polygon), 4 TryGetCollision (self, circle, obb, polygon -- upstream has no
10// TryGetCollision(BoundingCapsule2D) overload; Collision2D itself has no matching
11// TryGetCollisionAabbCapsule function, confirmed by reading Collision2D.hpp, so there is
12// genuinely nothing to wrap here -- this is not an omission). Everything else (fields,
13// properties, factory methods, GetCorners, Transform, Translate, Deconstruct, equality,
14// ToString) was already ported.
15//
16// Two asymmetric-argument-order quirks, both matching upstream exactly (not simplifications):
17// - Intersects(BoundingCircle2D)/TryGetCollision(BoundingCircle2D) call
18// Collision2D::IntersectsCircleAabb/TryGetCollisionCircleAabb (Collision2D has no
19// IntersectsAabbCircle/TryGetCollisionAabbCircle) -- TryGetCollision additionally calls
20// .Invert() on the result, since TryGetCollisionCircleAabb's MTV convention moves the
21// circle out of the box, but this method's contract moves the box out of the circle.
22// - Intersects(OrientedBoundingBox2D)/Intersects(BoundingPolygon2D)/their TryGetCollision
23// counterparts pass this box's Center/HalfExtents (not Min/Max) to the matching
24// Collision2D::*AabbObb/*AabbConvexPolygon functions, which take a center/half-extents AABB
25// representation -- unlike every other overload here, which passes Min/Max directly.
