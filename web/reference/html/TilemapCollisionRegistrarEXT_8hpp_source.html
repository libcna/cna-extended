13// Tilemap3DEXT cell and inserts it into a CollisionWorld3DEXT, so a voxel/block world's
14// static geometry doesn't need manual per-tile actor registration (the exact gap this phase
15// closes -- previously documented in NEXT.md as "today: insert one ICollisionActor3DEXT per
16// populated tile manually").
