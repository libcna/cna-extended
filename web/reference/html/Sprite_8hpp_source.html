5// Ported from MonoGame.Extended's Graphics/Sprite.cs. `Texture2DRegion TextureRegion` is a
6// std::shared_ptr<Texture2DRegion>, matching Texture2DRegion.hpp's shared-ownership convention
7// (a Sprite constructed directly from a Texture2D owns the region it creates; a Sprite
8// constructed from an atlas-owned or otherwise externally-owned region shares that ownership --
9// exactly the aliasing C#'s GC reference semantics give upstream "for free"). `object Tag` ->
10// `System::Object*`, matching GraphicsResource::getTagProperty()'s established convention for
11// this exact C# shape elsewhere in this ecosystem. `Vector2[] GetCorners(...)` (always length 4)
12// -> `std::array<Vector2, 4>`. Sprite has no virtual members in upstream (it is not `sealed` but
13// none of its members are declared `virtual`); `AnimatedSprite` extends it without overriding
14// anything, so no vtable is strictly required -- a virtual destructor is added anyway as ordinary
15// C++ hygiene for a base class with a real derived class.
