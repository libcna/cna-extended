5// Ported from MonoGame.Extended's ViewportAdapters/ViewportAdapter.cs: an abstract base decoupling
6// a game's virtual (design-time) resolution from the actual window/backbuffer resolution. Upstream
7// lives in the MonoGame.Extended.ViewportAdapters namespace; ported into a matching
8// CNA::Extended::ViewportAdapters sub-namespace, per this project's established
9// sub-namespace-per-module convention.
10//
11// `IDisposable` -> sharp-runtime's System::IDisposable. GraphicsDevice is taken by reference (not
12// pointer/value), matching CNA's own SpriteBatch::SpriteBatch(GraphicsDevice&) convention rather
13// than inventing a new one -- the adapter never owns the device, only references an
14// externally-owned, longer-lived one, same as upstream's GC-backed reference field.
