5// Ported from MonoGame.Extended's Particles/ParticleBuffer.cs: a circular buffer of raw,
6// unconstructed Particle memory. Upstream's `Marshal.AllocHGlobal(SizeInBytes)` (raw unmanaged
7// bytes, no constructor calls) -> `std::malloc`/`std::free` here, not `new Particle[]` (which
8// would default-construct every slot -- a real behavioral difference upstream deliberately avoids
9// via unmanaged allocation). Since `Particle` is a fixed-size POD, byte-pointer arithmetic on
10// upstream's `IntPtr NativePointer` is equivalent to `Particle*` pointer arithmetic here (which
11// auto-scales by `sizeof(Particle)`), so `NativePointer`/`Head`/`Tail`/`BufferEnd` are all typed
12// directly as `Data::Particle*` rather than mirroring the IntPtr-then-cast pattern. `GC
13// .Add/RemoveMemoryPressure` (informs the GC of unmanaged allocation size) has no C++ equivalent
14// (no GC) and is dropped.
