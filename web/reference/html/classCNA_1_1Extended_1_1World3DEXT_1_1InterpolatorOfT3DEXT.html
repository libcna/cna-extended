Detailed Description

template<typename T>
class CNA::Extended::World3DEXT::InterpolatorOfT3DEXT< T >

Generic interpolator base holding the start/end values to interpolate between.

Note
StartValue/EndValue have no in-class default initializer (unlike 2D's InterpolatorOfT<T>, where T StartValue;/EndValue rely on T being default- constructible) – Microsoft::Xna::Framework::Color (used by ColorInterpolator3DEXT) has no zero-argument constructor, so the protected constructor takes explicit initial values instead, and every concrete subclass (including float-valued ones like OpacityInterpolator3DEXT, where default construction would otherwise have been fine) passes them explicitly for consistency.
