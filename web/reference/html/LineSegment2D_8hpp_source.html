5// Ported from MonoGame.Extended's LineSegment2D.cs. Fields, Direction/Midpoint/Length/
6// LengthSquared, the constructor, GetBounds(), GetPoint(...), ClosestPoint(...) (a real
7// algorithm, but one that only uses Vector2 arithmetic, not Collision2D), Deconstruct,
8// Equals/GetHashCode/ToString/operators (Equals here is exact field equality, unlike Line2D's
9// epsilon-based Equals -- matches upstream, which does not use Collision2D.Epsilon in this
10// type's Equals) were ported before Collision2D existed.
11//
12// Now that Collision2D is fully ported, every deferred member is now ported:
13// - DistanceSquaredToPoint/DistanceToPoint -> Collision2D.DistanceSquaredPointSegment
14// - DistanceSquaredToSegment/DistanceToSegment -> Collision2D.DistanceSquaredSegmentSegment
15// - Intersects(Line2D, ...) -> Line2D::Intersects(LineSegment2D, ...)
16// - Intersects(Ray2D, ...) -> Ray2D::Intersects(LineSegment2D, ...)
17// - Intersects(LineSegment2D, ...) -> Collision2D.SolveParametricIntersection2D
18// - Intersects(BoundingBox2D/BoundingCircle2D/BoundingCapsule2D/OrientedBoundingBox2D, ...) ->
19// Collision2D.ClipLineToAabb / RayCircleIntersectionInterval / RayCapsuleIntersectionInterval
20// - Intersects(BoundingPolygon2D, ...) -> Collision2D.ClipLineToConvexPolygon (its degenerate
21// branch calls BoundingPolygon2D::Contains(Vector2), which was the last remaining blocker --
22// landed once BoundingPolygon2D's own Collision2D-dependent follow-up shipped).
23//
24// IMPORTANT correction to BoundingCapsule2D.hpp's deferred-method comment (written when
25// BoundingCapsule2D was ported, before this file existed): it assumed CreateFromSegment/
26// CreateMerged would become portable once LineSegment2D landed, then a later correction said that
27// was wrong because DistanceSquaredToPoint itself needed Collision2D. DistanceSquaredToPoint is
28// ported below now, so that second blocker is resolved too -- CreateFromSegment/CreateMerged can
29// be ported once BoundingCapsule2D.hpp itself is revisited (out of scope here; BoundingCapsule2D.hpp
30// is untouched by this change). See NEXT.md.
