5// Ported from MonoGame.Extended's ViewportAdapters/BoxingViewportAdapter.cs: a ScalingViewportAdapter
6// that letterboxes/pillarboxes to preserve aspect ratio while allowing a "safe" bleed area to be
7// cropped, tracking live window resizes via GameWindow::ClientSizeChanged.
8//
9// C#'s `window.ClientSizeChanged -= OnClientSizeChanged;` (Dispose()) has no direct C++ equivalent
10// -- sharp-runtime's System::EventHandler<T> has no operator-= (unsubscribe is token-based, via
11// Remove(Token), not handler-reference-equality). The Token returned by the constructor's
12// ClientSizeChanged += subscription is stored and passed to Remove() in Dispose(), achieving the
13// same effect through sharp-runtime's own established unsubscription mechanism.
14//
15// *** LIKELY UPSTREAM BUG, PRESERVED FOR FIDELITY -- see OnClientSizeChanged's inline comment ***
16// The Letterbox-vs-None branch compares `width >= clientBounds.Height` (WIDTH against the client
17// area's HEIGHT), not `clientBounds.Width` as the Pillarbox branch above it does -- looks like a
18// copy-paste error, reproduced exactly rather than "fixed."
