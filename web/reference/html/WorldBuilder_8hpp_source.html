5// Ported from MonoGame.Extended's ECS/WorldBuilder.cs. Upstream's `Build()` returns a `World`
6// (a GC-managed reference type, freely copyable-by-reference). `World` here owns a
7// `std::vector<std::unique_ptr<Systems::ISystem>>`, making it move-only at best -- returning it by
8// value would depend on the compiler eliding the move (guaranteed in some cases, not all) and adds
9// no value over the more idiomatic C++ alternative: `Build()` returns `std::unique_ptr<World>`,
10// giving the caller clear, singular ownership of the constructed World, matching how a `World` is
11// actually used in practice (built once, owned for the rest of its lifetime, never copied).
