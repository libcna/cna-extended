5// Ported from MonoGame.Extended's Serialization/Json/TextureRegion2DJsonConverter.cs. Unlike the
6// stateless value-type converters in this module (Color/Vector2/RectangleF/etc., all
7// `nlohmann::adl_serializer<T>` specializations), this needs a caller-supplied
8// `ITextureRegionService&` to resolve a region name to an actual `Texture2DRegion` -- there is no
9// way to inject that into nlohmann's fixed-signature ADL hooks. Ported instead as an explicit
10// class the caller constructs and invokes directly, matching C#'s per-instance `JsonConverter<T>`
11// object shape as closely as this project's JSON model allows.
