Detailed Description

template<typename T>
class CNA::Extended::Collections::Deque< T >

A double-ended queue backed by a circular array; elements can be added to or removed from either the front or the back in O(1) amortized time.

Template Parameters
TThe type of elements in the deque. Must support default construction, copy-assignment, and operator==.
