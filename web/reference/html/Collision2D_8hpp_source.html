5// Ported from MonoGame.Extended's Collision2D.cs: a static library of 2D collision-detection
6// primitives (containment, projection, distance, clipping, and intersection tests across
7// AABB/Circle/OBB/Capsule/ConvexPolygon shape pairs). This is the largest single file in this
8// port (3,809 lines upstream) and is being ported in several sequential chunks, each appending
9// to this same file -- see plan.md/NEXT.md for the chunk breakdown.
10//
11// Chunk 1 covered: Constants, Helpers, the full Containment region (all 5 shape-pair
12// sub-regions), and every dependency those methods transitively require to be genuinely
13// self-sufficient and correct -- which, in this tightly-coupled file, turned out to mean nearly
14// everything except the Parametric Solvers region, the Ray Interval methods, and the
15// `TryGetCollision*` overloads. Specifically it included: Constants/Helpers/Containment; the
16// full Projection region; the full Distance/ClosestPoint region; `ClipLineToAabb`/
17// `ClipLineToConvexPolygon` from the Clipping & Ray Intervals region (needed by the Distance
18// region, not the Ray Interval methods in that same region); and every plain-bool `Intersects*`
19// method from the Intersections region. See NEXT.md for the full account of why the
20// originally-planned narrower scope wasn't achievable in isolation.
21//
22// Chunk 2 (this one) completes the file: the Parametric Solvers region
23// (`SolveParametricIntersectionWithImplicitLine`, `SolveParametricIntersection2D`);
24// `ClosestPointRaySegment` (a leaf dependency of `RayCapsuleIntersectionInterval` below -- its
25// only caller, confirmed by reading the whole file) and the two Ray Interval methods
26// (`RayCircleIntersectionInterval`, `RayCapsuleIntersectionInterval`); and all 10
27// `CollisionResult2D`-producing `TryGetCollision*` overloads, each pairing with an
28// already-ported plain-`bool` `Intersects*` sibling from chunk 1. `Collision2D.cs` is now
29// 100% ported.
30//
31// `Vector2[]` array parameters -> `const std::vector<Vector2>&`, matching every other C#
32// array/`IList<T>` translation in this project. C#'s `out` parameters -> C++ reference
33// out-params. C#'s `ref` parameters (one `ClipInterval` overload) -> ordinary non-const C++
34// references.
