5// Ported from MonoGame.Extended's Collections/Pool.cs: a simple object pool with no intrusive
6// linked-list/IPoolable requirement (unlike ObjectPool<T> in the same folder). C#'s
7// `Func<T> createItem`/`Action<T> resetItem` map to `std::function<T*()>`/
8// `std::function<void(T*)>`, matching this project's established Func/Action-to-std::function
9// convention. T is a C# reference-type constraint (`where T : class`), so this pool works with
10// T* throughout, matching how ObjectPool<T>/GameComponentCollectionExtensions.hpp translate C#
11// reference-type generic parameters. Backed by the just-ported Deque<T*>.
12//
13// Note (preserved, not "fixed"): Free() calls resetItem unconditionally, even when the item was
14// NOT actually kept because _freeItems was already at _maximum -- matches upstream exactly (see
15// Free() below).
16//
17// Header-only: a template, matching this project's established convention for generic C# types.
