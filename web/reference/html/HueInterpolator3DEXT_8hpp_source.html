7// Not a literal 1:1 port of CNA::Extended::Particles::Modifiers::Interpolators::
8// HueInterpolator, which writes directly to Data::Particle::Color[0] (hue) since 2D's
9// Particle stores color natively as HSL -- no conversion needed. Particle3DEXT::ColorEXT is
10// plain RGB (see ColorInterpolator3DEXT.hpp's header comment for why this architecture
11// doesn't store HSL), so this class converts the particle's *current* color to HSL via
12// CNA::Extended::HslColor::FromRgb (reusing that existing utility rather than re-deriving
13// RGB<->HSL conversion), overwrites only the H channel with the interpolated value, and
14// converts back with HslColor::ToRgb -- preserving the current Saturation/Lightness exactly
15// as 2D's own "hue-only" semantic intends, just via a round-trip conversion instead of a
16// native HSL field. A small CNA::Extended::World3DEXT -> CNA::Extended (top-level, not
17// Particles-specific) dependency, matching Phase 11 A's UndefinedLayerException-reuse
18// precedent for utility types with no 2D-specific logic worth duplicating.
