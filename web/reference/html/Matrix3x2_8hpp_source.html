5// Ported from MonoGame.Extended's Math/Matrix3x2.cs. Upstream's X/Y/Z row properties use
6// `Unsafe.As<float, Vector2>` to alias pairs of fields as a Vector2 without copying; C++ has no
7// equally safe, portable equivalent (reinterpret_cast through unrelated types here would violate
8// strict aliasing), so getXProperty()/getYProperty()/getZProperty() construct a Vector2 by value
9// instead -- same observable values, different (safe) mechanism. `internal string
10// DebugDisplayString()` is a debugger-only helper (matches the precedent of skipping such members
11// elsewhere in this project) and is not ported. `object obj` Equals overload not ported (no C++
12// equivalent), matching precedent.
