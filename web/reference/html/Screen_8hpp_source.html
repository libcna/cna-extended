5// Ported from MonoGame.Extended's Screens/Screen.cs: an abstract base for game screens managed by
6// a ScreenManager. Upstream lives in the MonoGame.Extended.Screens namespace; ported into a
7// matching CNA::Extended::Screens sub-namespace, per this project's sub-namespace-per-module
8// convention.
9//
10// `ScreenManager ScreenManager { get; internal set; }` / `bool IsActive { get; internal set; }` --
11// C#'s `internal set` (assembly-visible, but not publicly settable) has no direct C++ equivalent;
12// approximated here via `friend class ScreenManager` + private setters, which is actually MORE
13// restrictive than `internal` (only ScreenManager itself can set these, not "any class in this
14// project"), but achieves the same practical intent -- these two properties exist purely for
15// ScreenManager's own bookkeeping.
