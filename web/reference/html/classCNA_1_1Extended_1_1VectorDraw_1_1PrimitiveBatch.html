Detailed Description

A low-level primitive batch that renders colored lines and filled triangles directly to the GPU using BasicEffect with vertex colors.

Remarks
Call Begin() before adding vertices and End() to flush all pending geometry to the GPU. This is the underlying renderer used by PrimitiveDrawing.
