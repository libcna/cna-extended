4// CNA::Extended::World3DEXT::BillboardRenderSystemEXT -- new, non-upstream addition. See
5// 3d.md/plan3d.md and BillboardComponentEXT.hpp's own header comment for the design.
6//
7// Each frame: for every entity with a BillboardComponentEXT, computes
8// Matrix::CreateScale(SizeEXT) * Matrix::CreateBillboard(objectWorldPosition, camera
9// position, camera up, nullopt) -- real CNA/XNA billboard math, always facing the camera
10// regardless of the entity's own Transform3ComponentEXT rotation (matching real billboard
11// semantics: only the entity's world *position* is used, not its rotation). Owns one
12// shared IndexBuffer (the constant {0,1,2,0,2,3} quad winding every BillboardComponentEXT's
13// VertexBufferEXT was built against, see BillboardMeshEXT.hpp) and one shared BasicEffect
14// (texture/tint swapped per draw call, matching CubeMeshRenderSystemEXT's identical pattern).
15//
16// DrawBillboardEXT exposes that same per-billboard draw step publicly, so other systems can
17// draw ad-hoc billboards (not backed by a BillboardComponentEXT entity) through this exact
18// path instead of duplicating it -- ParticleRenderSystem3DEXT uses this for per-particle
19// billboards, matching plan3d.md's Phase 7 requirement ("via Graphics3DEXT::
20// BillboardRenderSystemEXT's existing draw path, not a new one").
