Detailed Description

template<typename T>
class CNA::Extended::Collections::Pool< T >

A simple pool of reusable T* instances, backed by a circular-buffer Deque.

Template Parameters
TThe pooled type. Instances are managed by pointer (matching C#'s where T : class reference-type constraint).
