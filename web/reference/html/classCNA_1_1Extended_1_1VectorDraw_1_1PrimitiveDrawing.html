Detailed Description

Provides methods for drawing primitive shapes using a PrimitiveBatch.

Remarks
Call PrimitiveBatch::Begin() on the associated PrimitiveBatch before issuing any draw calls, and PrimitiveBatch::End() when finished to flush geometry to the GPU.
