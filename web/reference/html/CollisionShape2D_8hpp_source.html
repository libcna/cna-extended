5// Ported from MonoGame.Extended's CollisionShape2D.cs: a tagged-union `readonly struct` wrapping
6// one of 5 bounding-volume kinds (see CollisionShapeKind2D), dispatching Intersects/TryGetCollision
7// calls via nested switch statements to the corresponding bounding-volume type's own instance
8// methods -- all of which now exist (Collision2D and the full bounding-volume follow-up sweep are
9// complete; see NEXT.md entries (19)-(23)).
10//
11// Upstream stores only BoundingBox2D directly as a field (`_boundingBox`, doubling as this shape's
12// cached broadphase bounds) plus a small set of scalar/Vector2 "slots" (`_primary`/`_secondary`/
13// `_tertiary`/`_scalar`) reused differently per CollisionShapeKind2D, plus `_polygonVertices`/
14// `_polygonNormals` (reference-backed, not copied, per upstream's own documented design choice --
15// ported as std::vector<Vector2> copies here, since C++ value semantics for std::vector already
16// avoid the "copying arbitrary-size arrays into a value type" concern upstream's comment is about;
17// unlike C#, there is no reference-type array to alias). The private computed `Circle`/`OrientedBox`/
18// `Capsule`/`Polygon` C# properties (each reconstructing a fresh instance from the stored slots) are
19// ported as private getXProperty() methods, matching this project's established C# property
20// convention regardless of visibility.
21//
22// `internal bool TryGetLegacyPenetrationVector(...)` -- upstream's `internal` visibility has no C++
23// equivalent; kept public, matching the precedent set by CollisionResult2D::Invert() and
24// CollisionShapeKind2D elsewhere in this port. The `private static` legacy-penetration helper
25// methods (GetLegacyCircleCirclePenetrationVector/GetLegacyCircleBoxPenetrationVector/
26// GetLegacyBoxBoxPenetrationVector/Contains/GetClosestPoint) are ported as genuine C++ `private
27// static` member functions.
28//
29// No upstream test file exists for this type (confirmed: no CollisionShape2DTest.cs anywhere under
30// MonoGame.Extended.Tests) -- CollisionShape2DTests.cpp below is fresh test coverage, following the
31// "spot-check pair per delegation branch" convention used throughout this session's Collision2D
32// follow-up work, plus direct coverage of the legacy penetration vector helpers.
