5// Ported from MonoGame.Extended's ECS/EntitySubscription.cs (upstream `internal`, kept public per
6// this project's established internal-visibility convention). `event -= handler` (identity-based
7// unsubscription) has no direct C++ equivalent for lambda subscribers; translated using
8// `System::MulticastAction<int>`'s token-based `Add`/`Remove` (see that class's own header
9// comment for why). Preserved, not "fixed": upstream's `Dispose()` unsubscribes `EntityAdded`/
10// `EntityRemoved` but NOT `EntityChanged` -- a genuine upstream asymmetry (its `OnEntityChanged`
11// handler stays subscribed for the EntityManager's remaining lifetime even after this
12// EntitySubscription is disposed). Reproduced exactly: only two of the three tokens are removed
13// in Dispose() here too.
