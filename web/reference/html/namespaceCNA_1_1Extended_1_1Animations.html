enum class CNA::Extended::Animations::AnimationEventTrigger
strong

Identifies the kind of event raised by an IAnimationController during playback.

Enumerator
FrameBegin 

Raised when a frame begins being displayed.

FrameEnd 

Raised when a frame finishes being displayed.

FrameSkipped 

Raised when a frame is skipped over entirely (e.g. a very large elapsed-time update).

AnimationLoop 

Raised when a looping animation reaches its end and loops back.

AnimationCompleted 

Raised when a non-looping animation reaches its end and stops.

AnimationStopped 

Raised when the animation is stopped via Stop().
