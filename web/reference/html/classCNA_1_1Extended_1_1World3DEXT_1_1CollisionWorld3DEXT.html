Detailed Description

Stores 3D collision actors in named layers and provides broadphase, narrowphase, and pair-query operations.

Remarks
Layer filtering is explicit: collisions are considered only for layer pairs that have been enabled.
See also
ICollisionActor3DEXT, the interface your own game-object types implement to participate in a CollisionWorld3DEXT.
CollisionShape3DEXT for the low-level shape-vs-shape intersection/collision tests this class builds broadphase/narrowphase queries on top of.

Parameters

Remarks
When a default layer is set, self-collision is enabled for that layer and cross-layer collision is enabled between the default layer and every currently registered layer. Adding later non-default layers enables collision between those layers and the current default layer.
