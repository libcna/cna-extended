5// Ported from MonoGame.Extended's Tweening/LinearTween.cs. Upstream delegates arithmetic to
6// LinearOperations<T> (expression-tree-compiled +/-/* delegates, working around C#'s lack of
7// generic arithmetic operator constraints). LinearOperations<T> is ELIMINATED ENTIRELY in this
8// port -- not ported as a separate file, deliberately -- since C++ template code can use
9// operator+/operator-/operator*(T,float) directly: the compiler already enforces "T must support
10// these operations" via a plain compile error for any TMember that doesn't, which is strictly
11// better than C#'s runtime expression-tree compilation (a compile-time check instead of a
12// first-use runtime one). Interpolate() below computes `startValue_ + range_ * n` directly.
13//
14// Header-only: a template, matching this project's established convention for generic C# types.
