4// CNA::Extended::World3DEXT::SpatialHash3DEXT -- new, non-upstream addition. See
5// 3d.md/plan3d.md at the repository root for the design.
6//
7// 3D counterpart of CNA::Extended::Collisions::QuadTree, per plan3d.md Phase 5's "start
8// with the simplest correct version" scope decision. Design correction made during
9// implementation, documented transparently (matching this project's established practice
10// for such corrections -- see Camera3DEXT.hpp/ModelComponentEXT.hpp's own header
11// comments): rather than a true recursive octree with node splitting/merging (mirroring
12// QuadTree.cpp's own ~250-line recursive-subdivision implementation), this class is
13// implemented as a fixed-cell-size 3D spatial hash -- CNA::Extended::Collisions::
14// SpatialHash's own real, already-tested algorithm (a legitimate first-class 2D
15// broadphase in its own right, not a fallback) extended with a third (Z) axis. A uniform
16// grid hash generalizes far more directly from 2D to 3D than QuadTree's recursive
17// splitting logic does, while still being a real spatially-accelerated broadphase (not a
18// linear scan). True recursive octree subdivision can be added later as a separate
19// broadphase implementation if profiling ever shows a real need -- nothing in
20// ICollisionBroadphase3DEXT's interface or CollisionWorld3DEXT precludes swapping it in.
21//
22// Renamed from OctreeEXT (Phase 10, 2026-07-14, audit.md finding A-05): the class was
23// always honestly documented above as a spatial hash, not a hierarchical octree, but the
24// *name* itself still invited the opposite assumption for anyone who hadn't read this
25// comment. Renaming to match its actual algorithm (and CNA::Extended::Collisions::
26// SpatialHash's own naming) removes that ambiguity outright rather than relying on
27// documentation alone. This was a pure rename -- no behavior change; see plan3d.md's
28// Phase 10 entry for A-05's still-open performance concern (Query()'s O(K) std::find
29// duplicate check), which this rename does not address.
