5// Ported from MonoGame.Extended's Ray2D.cs. Fields, the constructor, CreateFromPoints, GetPoint,
6// ClosestPoint (a real algorithm, but pure Vector2 arithmetic -- not Collision2D),
7// DistanceSquaredToPoint/DistanceToPoint (both self-contained via ClosestPoint, unlike
8// LineSegment2D's equivalents which needed Collision2D), Normalize (3 overloads), Deconstruct,
9// and Equals/GetHashCode/ToString/operators were ported before Collision2D existed. Now that
10// Collision2D is fully ported, every Intersects(...) overload (against Line2D, Ray2D,
11// LineSegment2D, and all 5 bounding-volume types) is ported too: each one delegates to a real
12// Collision2D algorithm (SolveParametricIntersection2D, ClipLineToAabb,
13// RayCircleIntersectionInterval, RayCapsuleIntersectionInterval, ClipLineToConvexPolygon,
14// ClipInterval) or to a sibling method on Line2D. Ray2D.cs is now 100% ported.
