7// Not a literal 1:1 port of CNA::Extended::Particles::Modifiers::Interpolators::
8// ColorInterpolator, which interpolates in HSL space (Particle::Color is stored as HSL,
9// converted to RGB only at render time). Particle3DEXT::ColorEXT is a plain
10// Microsoft::Xna::Framework::Color (RGB+A), and ParticleEmitter3DEXT's own pre-existing
11// baked color-interpolation logic (before this architecture existed) already did a direct
12// per-channel RGB lerp, not HSL -- this class reproduces that exact RGB lerp (including
13// always emitting alpha=255, unchanged/not interpolated, matching the original) rather than
14// introducing HSL interpolation, which would be a real, visible color-path change, not a
15// pure refactor.
