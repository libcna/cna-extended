4// CNA::Extended::World3DEXT::World3DScreenEXT -- new, non-upstream addition. See
5// 3d.md/plan3d.md at the repository root for the design.
6//
7// Ties Phases 1-8 together into one convenience base class for real 3D game screens:
8// owns an ECS::World + Camera3DEXT, reusing Screens::Screen's real Initialize/LoadContent/
9// Update/Draw lifecycle and ScreenManager's existing stack/transition support as-is -- no
10// new Scene/SceneManager type (see 3d.md section 6.8 for why: Screen/ScreenManager already
11// fill that role for this whole project, a second parallel concept would just be
12// duplication).
13//
14// A derived screen class configures which systems its World owns by overriding
15// ConfigureWorldEXT (called once, from Initialize(), before the World is actually built)
16// -- e.g. adding RenderSystem3DEXT/CubeMeshRenderSystemEXT/BillboardRenderSystemEXT/
17// ParticleUpdateSystem3DEXT with a GraphicsDevice& and this screen's own GetCamera3DEXT().
18// A derived class overriding Initialize() itself must call World3DScreenEXT::Initialize()
19// first so GetWorld3DEXT() is valid before any of its own setup runs.
