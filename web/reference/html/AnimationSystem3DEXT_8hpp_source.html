4// CNA::Extended::World3DEXT::AnimationSystem3DEXT -- new, non-upstream addition. See
5// 3d.md/plan3d.md at the repository root for the design.
6//
7// Builds on: CNA::Extended::ECS::Systems::EntityUpdateSystem (this project's already-ported
8// ECS update-system base) and SkinnedModelComponentEXT/SkinnedModelEXT::ComputeBoneTransformsEXT
9// (real bone-hierarchy + keyframe-interpolation sampling, already implemented in cna -- see
10// SkinnedModelComponentEXT.hpp's header comment for why this is reused rather than
11// re-implemented). Each frame, advances every animated entity's PositionEXT by the frame's
12// elapsed time and recomputes BoneTransformsEXT; does not touch any Effect/GPU state itself
13// -- that happens in RenderSystem3DEXT.Draw(), see that header's own comment for why.
14//
15// A dedicated system rather than reusing Animations::AnimationController (the existing 2D
16// sprite-sheet frame-timing system, see 3d.md section 9.3): AnimationController's timing
17// model advances a discrete frame index through a fixed-duration-per-frame sprite sheet,
18// which doesn't fit continuous keyframe interpolation across arbitrarily-spaced
19// TimeSpan-keyed keyframes -- SkinnedModelEXT::ComputeBoneTransformsEXT already implements
20// the correct sampling for that, so this system is a thin per-entity driver over it, not a
21// new timing engine.
