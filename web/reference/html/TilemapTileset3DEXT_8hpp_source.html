5// 3d.md/plan3d.md at the repository root for the design.
6//
7// 3D counterpart of CNA::Extended::Tilemaps::TilemapTileset, deliberately scoped down:
8// maps a tile ID directly to a whole Texture2D (applied uniformly to all 6 faces of that
9// tile's cube by CubeMeshRenderSystemEXT::DrawCubeEXT), not upstream's per-tile source
10// rectangle within a shared texture atlas. A voxel/block world conventionally gives each
11// block type its own whole texture (or texture per face, itself out of scope here) rather
12// than packing many block types into one shared atlas the way a 2D tile sheet does --
13// matches plan3d.md's Phase 8 "decide the exact shape... based on what a real voxel/block
14// world actually needs".
