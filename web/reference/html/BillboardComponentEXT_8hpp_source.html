7// 3D counterpart of CNA::Extended::Graphics::Sprite: a camera-facing textured quad, driven
8// by Matrix::CreateBillboard (real CNA/XNA math) each frame by BillboardRenderSystemEXT.
9// Adapted from cna-scene::BillboardMesh/BillboardMeshRenderer's always-face-camera concept
10// (read as reference material only; see CubeMeshComponentEXT.hpp's header comment for why
11// no NOTICE.md entry is needed for cna-scene-informed design) -- re-implemented very
12// differently: cna-scene's BillboardMesh/BillboardMeshRenderer is an immediate-mode CPU
13// mesh builder + one-shot GPU uploader with no ECS integration, whereas this component
14// pairs with a per-entity VertexBufferEXT (baking that entity's own UV rect, since
15// different billboards/atlas frames need different UVs -- see
16// AnimatedBillboardComponentEXT.hpp for how the animated case updates it) and a shared
17// IndexBuffer/BasicEffect owned by BillboardRenderSystemEXT.
