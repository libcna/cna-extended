5// Ported from MonoGame.Extended's Math/ShapeExtensions.cs (upstream static class
6// `ShapeExtensions`). Despite living under the `Math/` folder upstream, its declared namespace is
7// the C# root `MonoGame.Extended` -- matching this project's "namespace follows the actual C#
8// declaration, not the file's folder" convention (see `Shapes::Polygon`/`Polyline`'s own header
9// comments for the same precedent), this ports into the root `CNA::Extended` namespace, not
10// `CNA::Extended::Graphics`, even though every method here is graphics-related. Extension methods
11// -> free functions, matching this project's established convention. `IReadOnlyList<Vector2>` has
12// no direct C++ equivalent; translated as `const std::vector<Vector2>&`, matching
13// `Polygon::getVerticesProperty()`'s own return type so `DrawPolygon(SpriteBatch&, Vector2,
14// const Polygon&, ...)` can forward its vertices directly.
15//
16// These methods are intended for prototyping/debug visualization only (per upstream's own doc
17// remarks): outline joints overlap (visible double-blending with semi-transparent colors), and
18// filled *shapes* other than plain rectangles are not supported here -- see
19// `CNA::Extended::VectorDraw::PrimitiveDrawing`/`PrimitiveBatch` (already ported, Phase 3) for
20// filled-shape drawing with correct alpha blending.
