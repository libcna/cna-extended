class  CNA::Extended::Particles::ParticleEffect
 A complete particle effect: a positioned/rotated/scaled container of one or more ParticleEmitters (e.g. an "explosion" effect might combine a fireball emitter, a smoke emitter, and a spark emitter). Move/rotate/scale the whole effect via Position/Rotation/ Scale, Trigger() it to release particles, and call Update() once per frame to advance every emitter's simulation. More...
