11// ComponentMapperOf<T> convention (see Transform3ComponentEXT.hpp) -- pairing a Model*
12// with a local-space BoundingSphere used for per-frame frustum culling by

14// hand-rolled draw call, Model::Draw(world, view, projection) already forwards to each
15// mesh's own per-part Effect (see Model.cpp) -- ModelComponentEXT would only be
