5// Ported from MonoGame.Extended's Tilemaps/Rendering/TilemapSpriteBatchRenderer.cs. Unlike
6// `TilemapRenderer`/`TilemapWorldRenderer` (both blocked -- see plan.md/NEXT.md's Rendering-phase
7// notes for the `DefaultEffect`/`VertexPositionColorTexture` incompatibility), this renderer draws
8// exclusively through `SpriteBatch::Draw`, which has no such dependency, so it ports in full.
9//
10// `Tilemap tilemap`/`LoadTilemap` -> non-owning `Tilemap*` (nullable, `nullptr` = "no tilemap
11// loaded", matching `_tilemap = null`); the renderer never owns the tilemap it draws, matching
12// this project's established externally-owned-resource convention. `SamplerState`/`Effect`
13// properties -> non-owning pointers for the same reason (`GetWrapSamplerState`'s own identity-
14// comparison convention, see TilemapRendererShared.hpp, requires SamplerState be pointer-typed
15// here too for consistency, though this class doesn't call GetWrapSamplerState itself -- upstream
16// doesn't either, see that file's header comment). `BlendState` -> stored **by value**, matching
17// `SpriteBatch::Begin`'s own by-value `BlendState` parameter (unlike `SamplerState`/`Effect`,
18// `BlendState`/`GraphicsResource` are copy-constructible small state-descriptor types in this
19// port, not GPU-handle owners -- see GraphicsResource.hpp).
20//
21// `SpriteBatch spriteBatch, OrthographicCamera camera` parameters (with
22// `ArgumentNullException.ThrowIfNull`) -> taken by reference (`SpriteBatch&`, `OrthographicCamera&`),
23// dropping the null checks, matching this project's established "reference-type-can't-be-null ->
24// dropped null checks" convention (both types are non-copyable in this port, so pass-by-reference
25// is the only viable translation regardless).
26//
27// The private nested `readonly record struct TileRenderPadding(Left, Top, Right, Bottom)` is kept
28// as a private nested struct here (not split into its own file) since nothing outside this class
29// ever references it, matching the "nested-detail-type stays nested" precedent already used
30// elsewhere in this codebase for types with a single internal consumer.
