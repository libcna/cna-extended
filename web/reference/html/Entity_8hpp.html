class  CNA::Extended::ECS::Entity
 A lightweight handle to a set of components tracked under a single stable integer ID. Entities are cheap to copy (just an ID plus two back-pointers) and carry no component data themselves – Attach/Get/Has/Detach all forward to per-component-type storage owned by the World's ComponentManager, keyed by this entity's ID.
