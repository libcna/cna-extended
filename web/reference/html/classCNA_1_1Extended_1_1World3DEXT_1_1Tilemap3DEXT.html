Detailed Description

A sparse 3D grid of tile IDs (0 == empty), addressed by integer cell coordinates and rendered as uniformly-sized cubes.

See also
Tilemap3DFactoryEXT for building one from hand-authored data.
TilemapRenderer3DEXT, which draws every non-empty cell as a cube.
