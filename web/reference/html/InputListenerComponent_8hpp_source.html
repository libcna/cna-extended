7// IUpdateable) -- ported as a plain single-base derivation from CNA's GameComponent, which
8// already implements IUpdateable transitively, avoiding a diamond re-declaration.

10// Upstream's `params InputListener[] listeners` constructor (a C#-only varargs convenience with
11// no direct C++ equivalent) -> a constructor taking `std::vector<std::unique_ptr<InputListener>>`
12// by value; the caller builds the vector explicitly instead of passing a variadic argument list.
13// This component owns every InputListener it's given (matching upstream's reference-type-handed-
14// off-and-stored intent), so listeners are stored via std::unique_ptr<InputListener>.
