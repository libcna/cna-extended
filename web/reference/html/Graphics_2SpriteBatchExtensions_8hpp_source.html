5// Ported from MonoGame.Extended's Graphics/SpriteBatch.Extensions.cs (upstream static class
6// `SpriteBatchExtensions`). Extension methods -> free functions in this namespace, matching this
7// project's established convention. `Sprite`/`SpriteBatch` receivers are taken by reference
8// (non-null by construction in C++); upstream's one explicit `if (sprite == null) throw
9// ArgumentNullException` check is therefore dropped, matching ActorPairKey.hpp's precedent for
10// reference-type parameters. `Texture2DRegion` parameters are `const
11// std::shared_ptr<Texture2DRegion>&`, matching Texture2DRegion.hpp's shared-ownership convention.
12// Upstream's `private static readonly Rectangle[] _patchCache` (a shared scratch buffer reused
13// across Draw(NinePatch) calls to avoid allocating) is kept as a translation-unit-local static
14// array in the .cpp, matching its role as a private implementation-detail cache rather than public
15// API; upstream's `private static Rectangle _rect = default` is dead code (declared, never read
16// or written anywhere in SpriteBatch.Extensions.cs) and is not ported.
