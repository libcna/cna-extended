7// Ownership: upstream's `WorldBuilder.Build()` constructs each registered `ISystem` beforehand and
8// hands it to `World.RegisterSystem`; after `Build()` returns, `World`'s own `_updateSystems`/
9// `_drawSystems` bags are the only remaining GC roots keeping those systems alive. This project
10// makes that ownership transfer explicit: `RegisterSystem` takes `std::unique_ptr<ISystem>` and
11// stores it in `systems_` (the true owning collection); the update/draw bags
12// (`updateSystems_`/`drawSystems_`) hold non-owning raw pointers into it, obtained via
13// `dynamic_cast` -- a direct translation of upstream's own `system is IUpdateSystem`/
14// `system is IDrawSystem` runtime pattern-match checks (a system can independently implement
15// either, both, or neither interface; `EntitySystem` alone implements neither -- only
16// `EntityUpdateSystem`/`EntityDrawSystem` and the base `UpdateSystem`/`DrawSystem` do).
