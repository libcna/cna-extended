5// Ported from MonoGame.Extended's Graphics/Texture2DAtlas.cs. `IEnumerable<Texture2DRegion>` ->
6// plain begin()/end() over the index-ordered region list, matching this project's first use of
7// this exact translation (no prior IEnumerable<T>-implementing type existed to establish a
8// precedent for). The dual `_regionsByIndex: List<T>` / `_regionsByName: Dictionary<string, T>`
9// storage is kept as-is (a std::vector alongside a System::Collections::Generic::Dictionary)
10// rather than routed through this project's own Collections::KeyedCollection<TKey,TValue>, since
11// KeyedCollection has no index-based access and upstream itself does not use its own
12// KeyedCollection for this type either. `params int[]`/`params string[]` -> `const
13// std::vector<int>&`/`const std::vector<std::string>&`. The `internal Texture2DRegion[]
14// GetRegions(ReadOnlySpan<IAnimationFrame> frames)` overload (used nowhere else in
15// MonoGame.Extended itself) is intentionally not ported in this pass -- it is dead code upstream
16// (grep confirms zero call sites outside this file) and porting it would pull an
17// Animations-module dependency into this header for no exercised behavior; add it later if a real
18// caller needs it.
