4// CNA::Extended::World3DEXT::Profile3DEXT -- new, non-upstream addition. See 3d.md/plan3d.md
5// at the repository root for the design.
6//
7// 3D counterpart of CNA::Extended::Particles::Profiles::Profile, brought to parity
8// (2026-07-14, user-requested): the first piece of the full Profiles/Modifiers/Interpolators
9// plugin architecture ParticleEmitter3DEXT previously lacked (see ParticleEmitter3DEXT.hpp's
10// own header comment, now updated, for the "why scoped down originally" history).
11//
12// One deliberate signature deviation from the 2D 1:1 mirror: GetOffsetAndHeading takes a
13// System::Random& parameter that upstream's Profile doesn't have (2D's concrete Profiles
14// draw from a global CNA::Extended::FastRandom::getSharedProperty() singleton instead).
15// World3DEXT has no equivalent global RNG and, more importantly, this project's established
16// 3D particle convention (ParticleEmitter3DEXT::randomEXT_) already keeps randomness
17// instance-owned per emitter for reproducibility -- a global shared RNG here would silently
18// decorrelate a Profile's draws from the rest of that same emitter's own random sequence
19// (lifetime/speed/scale sampling), which isn't behaviorally necessary and is worth avoiding.
