C++23 GAME-DEVELOPMENT TOOLKIT

Build on cna, not on missing infrastructure.

cna-extended is a C++23 port of MonoGame.Extended for the cna ecosystem. It supplies the practical systems that tend to recur in games: spatial queries, screen flow, input, sprite work, maps, particles, ECS, and a purpose-built 3D scene extension.

WHAT THIS LIBRARY IS

A layer of useful, composable game systems.

The library sits on cna, a C++23 XNA 4.0/FNA port, and sharp-runtime, a C++23 implementation of the required .NET BCL surface. Its 2D modules faithfully follow MonoGame.Extended wherever a direct C++ translation makes sense.

It is not a monolithic engine. You can use only the atlas loader and tweening, or combine maps, collision, screen management, particles, and ECS into a complete game. World3DEXT is an additional cna-extended 3D layer that deliberately reuses the same Screen and ECS foundations.

A PRACTICAL DEFAULT

Start with one vertical slice.

A player moving in a small map is enough to establish your input, timing, rendering, collision and asset-loading conventions.
