READING THE INCLUDE TREE

Paths mirror namespaces and usage areas.

A file under include/CNA/Extended/Tilemaps belongs to CNA::Extended::Tilemaps; the pattern makes targeted includes and IDE navigation predictable.

Prefer targeted headers

Include the module header for the type you actually use, for example <CNA/Extended/Tilemaps/Tiled/TiledTmxParser.hpp>. This communicates dependency intent and avoids relying on umbrella include details.

Use the umbrella for a quick orientation

<CNA/Extended.hpp> is useful when first exploring the library, but a production file usually benefits from direct module includes.
