02 · GETTING STARTED

Build against cna.

cna-extended is a C++23 static library. Check out cna and sharp-runtime beside this repository, then link the public CNA::Extended CMake target.

Build the library ↓Architecture
terminal
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DCNA_ENABLE_SDL=OFF -DCNA_ENABLE_VIDEO=OFF
cmake --build build --parallel 2
ctest --test-dir build -j2 --output-on-failure

CONFIGURATION

Start with the tested backend.

The standalone build links CNA by default and selects SOFTWARE, HEADLESS, and NULL. Select another renderer, platform, or audio backend for an application window.

CMake variableDefaultPurpose
CNA_EXTENDED_LINK_CNAONBuild and link the sibling CNA targets.
CNA_EXTENDED_CNA_RENDERERSOFTWARERenderer selected for the standalone build.
CNA_EXTENDED_CNA_PLATFORMHEADLESSWindow/input platform.
CNA_EXTENDED_CNA_AUDIO_PLATFORMNULLAudio backend.
CNA_EXTENDED_BUILD_EXAMPLESONBuild example programs.
CNA_EXTENDED_BUILD_TESTSONBuild and register GoogleTest cases.
i

With CNA_EXTENDED_LINK_CNA=OFF, CMake compiles the library against dependency headers only. That mode does not run the rendering tests or provide a linked runtime.

USE IT

Link the public target.

CMakeLists.txt
add_subdirectory(path/to/cna-extended)
add_executable(my_game main.cpp)
target_link_libraries(my_game PRIVATE CNA::Extended)
target_compile_features(my_game PRIVATE cxx_std_23)
